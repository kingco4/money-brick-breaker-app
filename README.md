# 💰 Money Brick Breaker (React)

A modern Brick Breaker / Breakout-style game built with **React + Canvas**.

## Features
- Money bills instead of bricks
- Broken money falls gracefully and can be collected
- Mouse & touch paddle control
- Smooth animations and physics
- Single-file React component
- No external dependencies

## Controls
- Mouse / Touch – Move paddle
- Click or Space – Launch ball
- P – Pause
- R – Reset

## Usage

```bash
# copy file
src/MoneyBrickBreaker.jsx
```

```jsx
import MoneyBrickBreaker from "./MoneyBrickBreaker";

export default function App() {
  return <MoneyBrickBreaker />;
}
```

Run:
```bash
npm start
```

## Tech
- React Hooks
- HTML5 Canvas
- Pure JavaScript
